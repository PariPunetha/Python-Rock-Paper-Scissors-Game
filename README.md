# 🎮 Rock, Paper, Scissors Game

A fun command-line game built with Python where you play Rock, Paper, Scissors against the computer. The computer makes a random choice, determines the winner, and lets you play multiple rounds.

## ✨ Features

- 🪨 Choose Rock, Paper, or Scissors
- 🤖 Random computer choice
- 🏆 Automatic winner detection
- 🔁 Play multiple rounds
- 💻 Simple and beginner-friendly interface

## 🛠️ Built With

- Python 3
- Random Module

## 🚀 How to Run

```bash
python rock_paper_scissors.py
```
